Getting started

One line. That's the whole setup.

Add the stylesheet to the <head> of any page. Everything else is just the HTML you already know how to write.

<link rel="stylesheet" href="yearn.css">

Or straight from a CDN, no download needed:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/immannino/yearn.css@0.1.0/dist/yearn.min.css">

Want a different palette? Load a theme after it. A theme is just a handful of CSS variables, so you can write your own from themes/_template.css.

<link rel="stylesheet" href="yearn.css">
<link rel="stylesheet" href="themes/dusk.css">

Fine-tune the mood with attributes on <html> — or try the panel in the corner. Press ⌘ K to imagine a command bar.

<html data-theme="dark" data-gradient="creamsicle" data-accent="pink">

FAQ

Questions, answered

Do I really not need any classes?

Really. Everything is keyed off semantic elements, with a few optional attributes like role="button" and data-gradient.

Can I change the fonts and colors?

Every value is a CSS custom property prefixed with --y-. Override them in your own stylesheet after yearn.css.

Does it work without JavaScript?

Yes. The only script on this page powers the demo panel and the dialog button below.
